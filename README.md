# Ứng dụng Quản lý Sinh viên (MERN Stack)

## Mô tả
Ứng dụng CRUD quản lý sinh viên sử dụng MongoDB, Express, React, Node.js.

## Công nghệ sử dụng
- Backend: Node.js, Express, Mongoose, MongoDB Atlas
- Frontend: React (Vite)

## Chức năng
- Xem danh sách sinh viên
- Thêm sinh viên mới
- Sửa thông tin sinh viên
- Xóa sinh viên

## Cách chạy dự án
1. Backend: `cd server && node server.js`
2. Frontend: `cd client && npm run dev`
